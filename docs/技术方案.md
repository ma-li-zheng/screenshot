## 二、功能清单（V1）

### 1. 截图
- 全局快捷键、托盘菜单、单实例运行、开机自启（可选）
- 支持多显示器，以及每个显示器缩放比例不同的情况（按物理像素截取，不模糊）
- 按下快捷键后屏幕冻结，四周变暗
- 鼠标悬停时自动识别窗口并高亮，单击直接选中；拖拽则是自由选区
- 放大镜：显示像素网格、坐标、RGB/HEX 颜色值，按 `C` 复制颜色
- 选区显示尺寸，有 8 个控制点可以调整，也可以整体拖动；方向键微调 1 px
- 右键：有选区时重新选，没有选区时退出；`Esc` 退出

### 2. 批注
- 工具：矩形、椭圆、箭头、直线、画笔、荧光笔、文字、马赛克、模糊、序号 ①②③
- 二级属性栏：粗细 3 档、8 种常用色加自定义颜色、字号
- 画好的图形可以再次选中、移动、删除；撤销/重做 `Ctrl+Z` / `Ctrl+Y`
- 输出：完成（复制到剪贴板，快捷键 `Enter` 或双击选区）、保存 `Ctrl+S`、钉到屏幕、提取文字、翻译、长截图、取消

### 3. 钉在屏幕
- 无边框、始终置顶、带阴影；可以同时钉多张
- 拖动移动、滚轮缩放（显示百分比）、`Ctrl+滚轮` 调透明度
- 双击或 `Esc` 关闭；右键菜单：复制、另存、透明度、恢复 100%、关闭全部
- 用 `Alt+Shift+P` 把剪贴板里的图片直接钉到屏幕

### 4. 提取文字（OCR）
- PaddleOCR 离线识别，图片不上传
- 结果窗口：左边原图上叠一层可以框选复制的文字，右边是可编辑的纯文本，保留换行
- 复制全部；也可以把识别结果直接送去翻译

### 5. 翻译
- 识别出的文字交给翻译接口，源语言自动检测；原文不是中文就译成中文，原文是中文就译成英文
- 对照模式：原文和译文对照显示，可以复制
- 覆盖模式：在原图每个文字框的位置填上背景色，再画上译文，生成翻译后的图片，可以复制、保存、钉到屏幕
- 设置页：选择服务商、填写 Key、测试连通性、查看本月已用字符数

### 6. 长截图
- 先选区，再点「长截图」进入滚动采集
- 支持手动滚动（鼠标滚轮）和自动滚动两种方式
- 选区旁边实时显示长图缩略图；点完成，或者检测到页面已经到底，就结束采集
- 结束后进入正常的批注编辑器

### 7. 设置
- 快捷键（注册失败时提示与其他软件冲突）
- 默认保存目录、文件名格式、PNG/JPG
- 开机自启
- 翻译服务配置

## 三、翻译免费方案调研结论

| 服务 | 每月免费额度 | 超出额度后 | 个人能否申请 | 结论 |
|---|---|---|---|---|
| **腾讯云机器翻译** | **500 万字符** | 按约 58 元/百万字符**自动扣费**（可以在控制台关闭后付费，额度用完就停止服务） | ✅ 实名认证 | **默认**。额度最大，国内访问快 |
| 百度翻译开放平台·高级版 | 100 万字符（标准版只有 5 万） | 49 元/百万字符 | ✅ 个人认证 | 备选 |
| 微软 Azure Translator F0 | 200 万字符 | **直接停止服务，不会扣费** | ✅ 需要 Azure 账号（可能要绑卡验证） | 备选，最不容易产生费用 |

- 估算：一次截图翻译通常是 100–500 字符，500 万字符大约够用 1 万次以上，个人使用基本不会超额。
- 防超额保护：软件在本地统计每个服务商当月用了多少字符，默认用到免费额度的 95% 就暂停调用并提示，这个阈值可以改。
- 明确不采用：
  - 非官方的网页翻译接口（例如 Google、Bing 网页版）：随时可能失效，也违反服务条款
  - 离线翻译模型：中英质量一般，而且要多 60 MB 以上
- Key 存放在 Windows 凭据管理器里，请求由 Rust 后端直接发给服务商。

## 四、总体架构

```
┌──────────────────────── Rust 后端 (src-tauri) ────────────────────────┐
│ shortcut   全局快捷键注册和冲突检测                                    │
│ tray       托盘菜单                                                    │
│ capture    xcap 多屏截取，Win32 枚举窗口矩形                            │
│ imgproto   自定义协议 shot://，把截图字节零拷贝交给前端                  │
│ windows    遮罩窗口、贴图窗口、结果窗口的创建和管理                      │
│ ocr        ONNX Runtime + PaddleOCR (检测、方向分类、识别)              │
│ translate  Provider 接口：Tencent / Baidu / Azure，用量统计            │
│ scroll     长截图：连续采集、模拟滚轮、拼接算法                         │
│ clipboard  复制图片和文本                                               │
│ settings   配置读写 (tauri-plugin-store)，凭据存储 (keyring)            │
└──────────────────────────────▲─────────────────────────────────────────┘
                               │ Tauri commands / events
┌──────────────────────── 前端 (src) ────────────────────────────────────┐
│ capture/   遮罩、选区、放大镜、窗口高亮、工具栏                         │
│ editor/    Konva 画板、各个工具、撤销栈、导出                           │
│ pin/       贴图窗口                                                    │
│ ocr/       OCR 和翻译结果窗口                                          │
│ scroll/    长截图控制条和预览                                           │
│ settings/  设置页                                                      │
└────────────────────────────────────────────────────────────────────────┘
```

**截图主流程**：快捷键 → Rust 截取所有显示器，同时记录窗口矩形 → 为每个显示器打开预先创建好的隐藏遮罩窗口，加载 `shot://` 里的图片 → 前端选区、批注 → 导出 PNG → 复制、保存或钉到屏幕。
**性能目标**：从按下快捷键到遮罩显示 ≤ 300 ms。遮罩窗口常驻、处于隐藏状态，用的时候不需要临时创建。

## 五、关键技术点

### 5.1 OCR（PaddleOCR 离线）
- 模型：PP-OCR 移动版的检测、方向分类、识别模型（ONNX 格式）加中文字典，约 15 MB；`onnxruntime.dll` 约 10 MB，随安装包一起分发。
- 推理：Rust 的 `ort` 库，只用 CPU。检测得到文字框，裁剪后做方向分类，再识别。
- 后处理：按坐标把文字框排序成行、合并成段落，输出 `[{text, box, score}]`。
- 性能：常规截图 0.3–1 s。识别在后台线程执行，界面显示加载状态。

### 5.2 翻译
- `trait Translator { fn translate(text, from, to) }`，三个实现：
  - 腾讯：TC3-HMAC-SHA256 签名
  - 百度：MD5 签名
  - Azure：Key 放在请求头
- 长文本按服务商的单次上限分段发送，并控制调用频率（腾讯 5 QPS、百度高级版 10 QPS）。
- 覆盖模式：每个 OCR 框分别翻译（同一段的框合并后再拆回去）。框的颜色取边缘像素的中位数作为背景色，字号按框高自动适配，排版用 Canvas 完成。

### 5.3 长截图
1. 采集期间遮罩窗口改为鼠标可穿透；选区边框和控制条调用 `SetWindowDisplayAffinity(WDA_EXCLUDEFROMCAPTURE)`，不出现在截屏结果里（需要 Win10 2004 及以上）。
2. 每 100–150 ms 截一次选区，和上一帧完全相同就跳过。
3. **拼接算法**：
   - 每一帧转灰度，计算每一行像素的哈希
   - 比较前后两帧，找出 dy，使上一帧的下半部分和当前帧的上半部分重合的行最多（先用行哈希快速对齐，再按像素差校验）
   - 连续多帧都没有变化的顶部和底部条带判定为固定区域（吸顶的标题栏、底栏），在长图里只保留一份
   - 每次只追加新出现的 dy 行
4. 自动滚动：用 `SendInput` 在选区中心发送滚轮消息，每次滚 1 格；连续 N 帧 dy = 0 就认为已经到底。
5. 限制：长图最高 30000 px；只支持竖向滚动；页面有动画或轮播时拼接可能错位，界面上会给出提示。

### 5.4 高 DPI 和多显示器
- 统一使用物理像素坐标，每个显示器独立一个遮罩窗口，避免跨屏时缩放比例混乱。
- 测试矩阵：100% / 125% / 150% / 200%，单屏，以及两块屏幕缩放比例不同。

## 八、风险与说明
- **没有代码签名**：安装时 SmartScreen 会提示「未知发布者」，点「仍要运行」即可。
- **DRM 内容**：受保护的视频画面截下来是黑的，这是系统限制。
- **独占全屏的游戏**：可能截不到或者无法覆盖，属于已知限制。
- **翻译 Key**：需要你自己去腾讯云、百度、Azure 申请。腾讯云建议在控制台关闭后付费，避免超额扣费。
- **开发环境**：Rust 加 VS Build Tools 约占 5 GB 磁盘，安装前会先征得你同意。
